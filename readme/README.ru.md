# Discord Rich Presence для TurboWarp

Добавьте Discord Rich Presence в игру TurboWarp с помощью пользовательского расширения и локального bridge.

**Важно:** расширение необходимо интегрировать в проект TurboWarp во время разработки, **до экспорта или компиляции игры**. Этот проект не может автоматически добавить RPC в уже экспортированную игру, в которой расширения не было.

## Возможности
- Настраиваемые описание, состояние и время активности Discord.
- Поддержка изображений Discord, сведений о группе, секретов Join/Spectate и флага экземпляра.
- Автоматическое переподключение к bridge.
- Локальный WebSocket на `127.0.0.1:32123`.
- Запуск в Windows через `game.bat`.
- Можно использовать скомпилированный `rpc_bridge.exe`, чтобы игрокам не требовался Python.

## Установка
1. Во время разработки загрузите `extension.js` в TurboWarp как пользовательское расширение **unsandboxed** и используйте его блоки в проекте.
2. Экспортируйте или скомпилируйте игру вместе с расширением.
3. Создайте приложение в [Discord Developer Portal](https://discord.com/developers/applications) и скопируйте Application ID.
4. Укажите числовой ID в `APP_ID` файла `resources/rpc/rpc_bridge.py`. Не добавляйте bot token или client secret.
5. Скопируйте содержимое `ingame/` рядом с исполняемым файлом игры.
**Важно:** откройте `resources/rpc/rpc_bridge.py` и замените `testdiscordrpc.exe` в `GAME_EXE` точным именем скомпилированного исполняемого файла игры, расположенного в корневой папке игры (рядом с `game.bat`). Сохраните расширение `.exe` и кавычки. Например, для `MyGame.exe` укажите `GAME_EXE = GAME_DIR / "MyGame.exe"`.

Сначала скрипт ищет `resources/rpc/rpc_bridge.exe`. Если файла нет, он ищет Python 3 и устанавливает зависимости при первом запуске. Настройте Application ID до компиляции bridge. Настольное приложение Discord должно быть запущено, а пользователь — войти в аккаунт.

## Блоки расширения
- **set [field] to [value]** — настроить поле активности.
- **update presence** — отправить данные в Discord.
- **clear presence** — очистить активность.
- **reconnect to bridge** — повторить подключение.
- **RPC connection status** — проверить подключение и последнюю ошибку.
- **current value of [field]** — прочитать текущее значение поля.

Временные метки задаются в секундах Unix, не миллисекундах. Для изображений нужны ключи ресурсов из Discord Developer Portal, а не URL картинок.

## Решение проблем
- Нет соединения: убедитесь, что bridge запущен, а расширение загружено в режиме unsandboxed.
- Нет активности: проверьте Discord Desktop и Application ID.
- Нет изображений: проверьте ключи Rich Presence.
- Открытие `http://127.0.0.1:32123/` в браузере не является проверкой: endpoint ожидает WebSocket.

## Безопасность
Bridge принимает соединения только на локальном адресе `127.0.0.1`. Не открывайте доступ другим устройствам, если не понимаете риски.
